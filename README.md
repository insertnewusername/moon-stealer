# Moon stealer

This is a 2d godot platformer, focused on getting to the top!
There are several enemies in your way, in which you slice through them
<h2>Features</h2>
Attack
Move around
Moving enemies
Trampolines
Teleport pads
Looks cool!

<h2>Languages used</h2>
Godotscript...

<h2>Controls</h2>
WASD or arrow keys - Move around jump etc
Spacebar - Attack
Run into enemy - die
